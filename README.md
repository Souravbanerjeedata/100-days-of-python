## 🛠️ How to Run the Projects

1. Clone the repository:

```bash
git clone https://github.com/Souravbanerjeedata/100-days-of-python.git
```

2. Navigate into the desired day folder:

```bash
cd "Day XX"
```

3. Run the main file:

```bash
python main.py
```

> **Note**: Some projects use external libraries (e.g. `turtle`, `pandas`, `flask`, `selenium`). Install any required packages listed in the day folder if needed.
